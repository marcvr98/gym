# gym_things

Proyecto simple de scraping para acceder a https://wodboxtraining.aimharder.com y mostrar información básica (título, meta descripción y enlaces).

Requisitos:
- Python 3.8+
- `requests` y `beautifulsoup4`

Instalación:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Uso:

```bash
python main.py
```
